# 06_i2c_sensor_suite — 三传感器共线首发（BME280 + MPU6050 + OLED）
> 电路连接图见 [`../04_uav_telemetry_mqtt/docs/circuit-uav-lab-01.svg`](../04_uav_telemetry_mqtt/docs/circuit-uav-lab-01.svg)（本工程 = 图中实线部分：ESP32-S3 + BME280 + MPU6050 + OLED 同一条 I2C 总线）。


自费玩一套的核心预演：**一条 I2C 总线挂全部传感器**——这就是 04 遥测节点的最终形态。
INA219（0x40）到货后挂上第 4 个地址，即为完整四件套。

驱动策略有讲究：

- **MPU6050 手写裸寄存器驱动**（40 行）：写 4 个寄存器、连续读 14 字节——直观展示"I2C 器件 = 寄存器读写"的本质，且不卡 WHO_AM_I 校验（国产兼容芯照常用）；
- **BME280 / OLED 用 Adafruit 库**：温度补偿算法与显存刷新太复杂，不自研。

## 接线（面包板共线，公对公跳线 12 根）

ESP32 双排针**骑跨面包板中间凹槽**自然插入（两排正好相距 10 孔距，能插上）；
插下后**每个引脚所在列还剩 4 个孔 = 这根引脚的分线插孔**。三模块插在面包板空余区，然后：

```
3V3 那一列 ──┬── 公对公线 ── BME280 VCC
             ├──             MPU6050 VCC
             └──             OLED   VCC      （GND / SDA / SCL 同理各引 3 根）
```

| 丝印 | BME280（6 焊盘） | MPU6050（GY-521，8 脚） | OLED 0.96"（4 脚） |
|------|------------------|--------------------------|---------------------|
| VCC  | 3V3              | VCC → 3V3                | VCC → 3V3           |
| GND  | GND              | GND → GND                | GND → GND           |
| SCL  | GPIO 9           | SCL → GPIO 9             | SCL → GPIO 9        |
| SDA  | GPIO 8           | SDA → GPIO 8             | SDA → GPIO 8        |
| 悬空 | CSB、SDO         | XDA、XCL、AD0、INT 全悬空 | —                   |

> 各模块丝印顺序可能不同（OLED 常见 GND,VCC,SCL,SDA），**一律以各自丝印为准**，别按位置照搬。

## 运行

```bash
./run.sh sensors    # 板插丝印「UART/COM」口
```

## 串口判读

| 现象 | 结论 |
|---|---|
| 扫到 `0x68 + 0x76 + 0x3C` 三器件 + 三行"就绪" + ✅ | 全通，OLED 屏上应实时显示数据 ✔ |
| 缺某个器件 | 缺谁查谁的四根线（I2C 不分主次，地址扫不到就是那模块的线没插实） |
| 全没扫到 | 查 SDA/SCL 是否插到了相邻的 3 或 46 脚上（目标是 8 和 9） |
| MPU WHO_AM_I ≠ 0x68 | 国产兼容芯正常现象，照常出数 |
| OLED 地址在扫但黑屏 | 拍模块背面丝印核对地址（0x3C/0x3D），部分带对比度电位器可调 |

## 读数常识

- **Roll/Pitch 是加速度计姿态角**：静止摆放时准（重力投影），晃动时漂——滤波融合（互补/卡尔曼）是 T1.2 和毕设 #4 的正戏；
- **gz 是偏航角速度**（°/s）：静止应近 0，水平转动立刻响应；绝对 yaw 需积分（会漂）；
- MPU6050 自带温度是**芯片温度**（比室温高 3~5°C），别当气温用；
- 随手验证：板子前倾，Pitch 变负；右倾，Roll 变正（桌面平放两者应近 0±2°）。
