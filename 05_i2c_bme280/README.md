# 05_i2c_bme280 — I2C 总线扫描 + BME280 温/压/湿/气压高度

自费玩一套·首个外设传感器点亮工程，两个作用：

1. **验收**：到货的 BME280 是不是真芯——BME280 芯片 ID=0x60；市面上常见拿无湿度通道的 BMP280（ID=0x58）冒充，读一下便知；
2. **总线底座**：开机先扫描 I2C 全总线。之后 MPU6050（0x68）/INA219（0x40）/OLED（0x3C）到货，都先跑本工程认地址、排查接线。

本工程同时是 04 遥测节点 `alt` 字段的实测来源（契约 §1 映射：alt←BME280 气压高度）。

## 接线（信号对应关系）

| BME280 丝印 | ESP32-S3 DevKitC-1 | 说明 |
|---|---|---|
| VCC | 3V3 | 3.3V 款无稳压，**严禁插 5V** |
| GND | GND | 共地 |
| SCL | GPIO 9 | I2C 时钟（四传感器共享总线） |
| SDA | GPIO 8 | I2C 数据 |
| CSB / SDO（6 焊盘款才有） | 悬空 | SPI 备用脚。I2C 下 CSB 定协议（拉高=I2C）、SDO 定地址（悬空/接地=0x76，接 VCC=0x77）——模块板载电阻已拉好，固件 0x76/0x77 自动识别，无需任何操作 |

两种接法任选其一：

1. **母对母杜邦线 4 根直连**——模块和开发板两侧都是公排针，公对公插不上；
2. **面包板 + 公对公（或公对母）跳线**——ESP32 横跨面包板中间凹槽插入（每行外侧还剩 4 孔可走线），BME280 插在空余区，4 根跳线按上表连接。等其余传感器到货共线时本来就要上面包板，可提前熟悉。

## 运行

```bash
./run.sh bme        # 编译 + 烧录 + 串口监视（板插丝印「UART/COM」口）
```

## 串口判读

| 现象 | 结论 |
|---|---|
| `发现器件 0x76`（或 0x77）+ `芯片 ID 0x60`，随后每 2s 打印 T/P/H/高度 | 正品，收工 ✔ |
| 一个器件都扫不到 | 接线问题：VCC 是否 3V3、GND 是否共地、SDA/SCL 是否插反或未插实 |
| 扫到地址但 ID=0x58（或湿度列 nan） | **BMP280 假芯**，无湿度通道 → 截图串口找店家退换 |

## 读数常识（不是故障）

- **温度比室温高 1°C 左右**：芯片连续采样自热，正常现象；
- **气压高度两列口径不同**：`气压高度` = 标准大气压折算的绝对值（厦门真实海拔 ±30m 漂）；`相对开机` = 上电归零的相对值，**这才是契约 alt 字段的口径**——拿着板子爬一层楼，它应该 +3m 左右；
- 厦门室内典型值参考：T≈24–28°C，P≈1005–1015hPa，H≈55–75%RH。
